# Лабораторная работа № 8. BGP. Фильтрация

Цель — ограничить BGP-анонсы Москвы и Санкт-Петербурга, исключить использование
офисов как транзитных AS и сохранить доступность IPv4-сетей стенда.

## План и изменения

| Устройство | Настройка |
|---|---|
| R14, R15 — Москва, AS 1001 | Исходящий `filter-list 10` с AS-path `^$`: провайдерам передаются только маршруты, возникшие внутри AS 1001 |
| R18 — Санкт-Петербург, AS 2042 | Исходящий `SPB-EXPORT4` на обоих провайдерских соседях: только собственные префиксы |
| R22 — Киторн, AS 101 | В сторону R14 разрешён только `0.0.0.0/0`; default создаётся командой `neighbor default-originate` |
| R21 — Ламас, AS 301 | В сторону R15 разрешены только `0.0.0.0/0` и `10.20.0.0/16` |
| R14, R15 — передача default в OSPF | Default объявляет пограничный роутер, у которого выбран маршрут через собственного провайдера; проверяется next hop |

## Передача маршрутов

AS-path `^$` разрешает пустой путь AS до добавления номера локальной AS.
Внешние маршруты этим условием не допускаются к повторному анонсу провайдерам.
В Петербурге prefix-list разрешает точные префиксы `10.20.0.0/16`,
`10.20.255.18/32`, `10.254.0.36/30` и `10.254.0.40/30`.

В Москве сохранён Local Preference 200 от Ламаса и 100 от Киторна.
Внешний трафик идёт через R15, а R14 служит резервом. Условная передача default
в OSPF исключает петлю через внутренние маршрутизаторы.
Префикс Петербурга передаётся в OSPF существующей политикой `BGP-INTO-OSPF`.
Москва использует default для сетей, скрытых входящей фильтрацией.
