# Команды настройки

[К отчёту](../README.md).

Команды использованы для настройки стенда после четвёртой лабораторной.
Они сохранены для описания изменений; повторно вводить их не требуется.
На Cisco в файлах уже есть вход в режим настройки и сохранение через `write memory`.
На VPC выполняются `ip auto` и `save`.
