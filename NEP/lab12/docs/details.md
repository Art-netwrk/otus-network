# Адресация и пересылка

| PE | Транспортный IPv4 /32 | Сервисный IPv4 /32 | iBGP-сосед |
|---|---|---|---|
| R14 | 10.255.0.14 | 198.18.12.14 | 10.255.0.15 |
| R15 | 10.255.0.15 | 198.18.12.15 | 10.255.0.14 |
| R18 | 10.252.12.18 | 198.18.12.18 | 10.252.12.32 |
| R32 | 10.252.12.32 | 198.18.12.32 | 10.252.12.18 |

В Москве R14 отправляет помеченные пакеты через Ethernet0/0 к R12 либо Ethernet0/1 к R13. Для FEC 10.255.0.15/32 в контрольном снимке обе записи на R14 содержали исходящую метку 29. Во время серии из 20 запросов вырос счётчик R12, а на R13 он остался равен 1350 байтам.

В Петербурге R18 получает транспортный маршрут 10.252.12.32/32 через EIGRP с next hop 10.20.0.2. При пересылке на R16 через Ethernet0/0 R18 использует метку 26. R16 снимает её и отправляет пакет через Ethernet0/3 к 10.20.0.26 на R32.
